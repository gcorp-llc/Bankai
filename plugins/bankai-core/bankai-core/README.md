# Bankai SEO Suite – Primer UI v2

طراحی کامل بر اساس سیستم Primer (GitHub) + Alpine.js

## جایگزینی

```
bankai-core/
├── functions.php
├── inc/class-editor-seo.php
├── inc/meta/class-post-seo-meta.php
├── inc/modules/class-seo-engine.php
├── views/tab-seo-engine.php
└── assets/
    ├── css/editor-seo.css          ← طراحی کامل Primer
    ├── js/editor-seo.js
    └── js/editor-seo-gutenberg.js
```

## ویژگی‌های UI
- هدر چسبان با آیکون سپر و بج «متای پست»
- تب‌های Pill (سئو / سرعت / اسکیما / سوشال / AI)
- پیش‌نمایش SERP دسکتاپ/موبایل
- کلیدواژه chip + تراکم
- نوار پیشرفت عنوان و توضیحات
- دونات امتیاز + آکاردئون ممیزی
- سوئیچ‌های Robots
- فوتر Live Sync
- دکمه toolbar: سپر + نقطه سبز
